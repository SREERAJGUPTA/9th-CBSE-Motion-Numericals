1. Formula Cheat Sheet

A. Average Speed and Average Velocity

QuantityFormulaMeaning
Average Speed $\text{Average Speed} = \dfrac{\text{Total Distance}}{\text{Total Time}}$ Scalar quantity. Depends on the complete path length.
Average Velocity $\text{Average Velocity} = \dfrac{\text{Total Displacement}}{\text{Total Time}}$ Vector quantity. Depends on change in position and direction.

B. Important Shortcut Cases

CaseFormula / Result
Equal distances with speeds $v_1$ and $v_2$ $\text{Average Speed} = \dfrac{2\,v_1\,v_2}{v_1 + v_2}$
Equal time intervals with speeds $v_1$ and $v_2$ $\text{Average Speed} = \dfrac{v_1 + v_2}{2}$
Return trip to the same point $\text{Average Velocity} = 0$, because displacement $= 0$
💡 Core Idea Speed cares about distance. Velocity cares about displacement. This single difference explains most average speed vs average velocity questions.

C. Three Standard Equations of Motion

Equations of Uniformly Accelerated Motion
$$v = u + at$$ 1st Equation
$$s = ut + \tfrac{1}{2}\,a\,t^2$$ 2nd Equation
$$v^2 - u^2 = 2\,a\,s$$ 3rd Equation
EquationUse When
$v = u + at$Time, acceleration, initial velocity, and final velocity are involved.
$s = ut + \frac{1}{2}\,a\,t^2$Distance / displacement is asked and time is given.
$v^2 - u^2 = 2\,a\,s$Time is not given or not required.

D. Symbols and Meanings

SymbolMeaning
$u$Initial velocity
$v$Final velocity
$a$Acceleration
$t$Time
$s$Distance / Displacement

E. Derived / Reduced Formulas

1. Motion from Rest
If the body starts from rest, $u = 0$
$$v = at$$ $$s = \tfrac{1}{2}\,a\,t^2$$ $$v^2 = 2\,a\,s$$
2. Stopping Distance
If the body comes to rest, $v = 0$
$$0 = u^2 + 2\,a\,s$$ $$s = \frac{u^2}{2\,|a|}$$
3. Retardation / Deceleration
If speed decreases, acceleration is negative.
$$a = \frac{v - u}{t}$$
4. Free Fall
$a = g$; take $g = 10\;\text{m/s}^2$ for Grade 9
$$v = g\,t$$ $$s = \tfrac{1}{2}\,g\,t^2$$ $$v^2 = 2\,g\,s$$

3. Step-by-Step Answer Key and Pedagogy

📖 How to Read the Solutions Each solution follows the same physics habit: write given values, convert units, choose the formula, substitute carefully, and interpret the sign of acceleration or velocity.
Solution 1: Speed Battle on a Straight Road
Given

$v_1 = 60\;\text{m/s}$,   $t_1 = 10\;\text{min} = 600\;\text{s}$

$v_2 = 50\;\text{m/s}$,   $t_2 = 5\;\text{min} = 300\;\text{s}$

Calculation

Distance in first part:

$$s_1 = v_1 \times t_1 = 60 \times 600 = 36{,}000\;\text{m}$$

Distance in second part:

$$s_2 = v_2 \times t_2 = 50 \times 300 = 15{,}000\;\text{m}$$

Total distance:

$$s_1 + s_2 = 36{,}000 + 15{,}000 = 51{,}000\;\text{m}$$

Total time:

$$600 + 300 = 900\;\text{s}$$
Formula Used
$$\text{Average Speed} = \frac{\text{Total Distance}}{\text{Total Time}}$$
Substitution & Result
$$\text{Average Speed} = \frac{51{,}000}{900} = 56.67\;\text{m/s}$$

Since the car moves in the same straight direction, displacement equals distance.

$$\text{Average Velocity} = \frac{51{,}000}{900} = 56.67\;\text{m/s}$$
✅ Final Answer Total distance $= 51{,}000\;\text{m}$  |  Average speed $= 56.67\;\text{m/s}$  |  Average velocity $= 56.67\;\text{m/s}$
⚠️ Common Trap Do not directly average $60$ and $50$ because the time intervals are unequal.
Solution 2: Morning Run Challenge
Given

$s_1 = 100\;\text{m}$,   $t_1 = 3\;\text{min} = 180\;\text{s}$

$s_2 = 50\;\text{m}$,   $t_2 = 1\;\text{min} = 60\;\text{s}$

Calculation
$$\text{Total distance} = 100 + 50 = 150\;\text{m}$$ $$\text{Total time} = 180 + 60 = 240\;\text{s}$$
Formula Used
$$\text{Average Speed} = \frac{\text{Total Distance}}{\text{Total Time}}$$
Substitution & Result
$$\text{Average Speed} = \frac{150}{240} = 0.625\;\text{m/s}$$
✅ Final Answer Total distance $= 150\;\text{m}$  |  Total time $= 240\;\text{s}$  |  Average speed $= 0.625\;\text{m/s}$
⚠️ Common Trap Average speed is not found by averaging individual speeds unless equal time intervals are given.
Solution 3: Boat Ride and Return Trip
Given

First journey: $v_1 = 60\;\text{km/h}$,   $t_1 = 4\;\text{min} = \frac{4}{60}\;\text{h}$

Return journey: $v_2 = 120\;\text{km/h}$,   $t_2 = 2\;\text{min} = \frac{2}{60}\;\text{h}$

Calculation

Distance from pier to island:

$$s_1 = v_1 \times t_1 = 60 \times \frac{4}{60} = 4\;\text{km}$$

Return distance:

$$s_2 = 120 \times \frac{2}{60} = 4\;\text{km}$$ $$\text{Total distance} = 4 + 4 = 8\;\text{km}$$ $$\text{Total time} = 4 + 2 = 6\;\text{min} = \frac{6}{60}\;\text{h} = 0.1\;\text{h}$$
Formula Used
$$\text{Average Speed} = \frac{\text{Total Distance}}{\text{Total Time}} \qquad \text{Average Velocity} = \frac{\text{Total Displacement}}{\text{Total Time}}$$
Substitution & Result
$$\text{Average Speed} = \frac{8}{0.1} = 80\;\text{km/h}$$

Since the boat returns to the starting point, displacement $= 0$.

$$\text{Average Velocity} = \frac{0}{0.1} = 0$$
✅ Final Answer Distance to island $= 4\;\text{km}$  |  Total distance $= 8\;\text{km}$  |  Average speed $= 80\;\text{km/h}$  |  Average velocity $= 0$
💡 Tip Distance is $8\;\text{km}$, but displacement is $0$. That is why average speed is not zero, but average velocity is zero.
Solution 4: Bullet Train Launch
Given

$u = 0$,   $v = 300\;\text{km/h}$,   $t = 6\;\text{min} = 360\;\text{s}$

Unit Conversion
$$v = 300 \times \frac{5}{18} = 83.33\;\text{m/s}$$
Formula Used
$$v = u + at$$
Substitution
$$83.33 = 0 + a \times 360$$ $$a = \frac{83.33}{360} = 0.231\;\text{m/s}^2$$
Distance (2nd Equation)
$$s = ut + \tfrac{1}{2}\,a\,t^2 = 0 + \tfrac{1}{2} \times 0.231 \times (360)^2$$ $$s = 15{,}000\;\text{m} = 15\;\text{km}$$
✅ Final Answer $\boxed{a = 0.231\;\text{m/s}^2}$  |  $\boxed{s = 15{,}000\;\text{m} = 15\;\text{km}}$
💡 Tip Always convert km/h into m/s before using equations of motion with seconds.
Solution 5: Bus Slowing Down
Given

$u = 60\;\text{km/h}$,   $v = 30\;\text{km/h}$,   $t = 3\;\text{s}$

Unit Conversion
$$u = 60 \times \frac{5}{18} = 16.67\;\text{m/s}$$ $$v = 30 \times \frac{5}{18} = 8.33\;\text{m/s}$$
Formula Used
$$v = u + at$$
Substitution
$$8.33 = 16.67 + a \times 3$$ $$a = \frac{8.33 - 16.67}{3} = \frac{-8.34}{3} = -2.78\;\text{m/s}^2$$
Distance
$$s = \frac{u + v}{2} \times t = \frac{16.67 + 8.33}{2} \times 3 = 12.5 \times 3 = 37.5\;\text{m}$$
✅ Final Answer $\boxed{a = -2.78\;\text{m/s}^2}$  |  $\boxed{s = 37.5\;\text{m}}$
💡 Tip Negative acceleration does not always mean the object is moving backward. Here it means the bus is slowing down.
Solution 6: Playground Slide Motion
Given

$u = 0$,   $a = 10\;\text{cm/s}^2$,   $t = 10\;\text{s}$

Unit Conversion
$$a = 10\;\text{cm/s}^2 = 0.10\;\text{m/s}^2$$
Formula Used & Substitution
$$v = u + at = 0 + 0.10 \times 10 = 1\;\text{m/s}$$ $$s = ut + \tfrac{1}{2}\,a\,t^2 = 0 + \tfrac{1}{2} \times 0.10 \times (10)^2 = 0.05 \times 100 = 5\;\text{m}$$
✅ Final Answer $\boxed{v = 1\;\text{m/s}}$  |  $\boxed{s = 5\;\text{m}}$
💡 Tip $10\;\text{cm/s}^2$ looks small, but over time it still increases velocity.
Solution 7: Emergency Braking of a Train
Given

$u = 100\;\text{km/h}$,   $v = 0$,   $a = -10\;\text{m/s}^2$

Unit Conversion
$$u = 100 \times \frac{5}{18} = 27.78\;\text{m/s}$$
Time to Stop (1st Equation)
$$v = u + at$$ $$0 = 27.78 - 10\,t$$ $$t = \frac{27.78}{10} = 2.78\;\text{s}$$
Stopping Distance (3rd Equation)
$$v^2 - u^2 = 2\,a\,s$$ $$0 - (27.78)^2 = 2 \times (-10) \times s$$ $$-771.73 = -20\,s$$ $$s = \frac{771.73}{20} = 38.6\;\text{m}$$
✅ Final Answer $\boxed{t = 2.78\;\text{s}}$  |  $\boxed{s = 38.6\;\text{m}}$
⚡ Shortcut Stopping distance: $s = \dfrac{u^2}{2\,|a|}$
Solution 8: Cricket Ball Coming to Rest
Given

$u = 150\;\text{km/h}$,   $v = 0$,   $t = 10\;\text{s}$

Unit Conversion
$$u = 150 \times \frac{5}{18} = 41.67\;\text{m/s}$$
Formula Used & Substitution
$$v = u + at$$ $$0 = 41.67 + a \times 10$$ $$a = \frac{-41.67}{10} = -4.17\;\text{m/s}^2$$
Distance Before Stopping
$$s = \frac{u + v}{2} \times t = \frac{41.67 + 0}{2} \times 10 = 20.835 \times 10 = 208.35\;\text{m}$$
✅ Final Answer $\boxed{a = -4.17\;\text{m/s}^2}$  |  $\boxed{s = 208.35\;\text{m}}$
💡 Tip When an object stops, final velocity $v = 0$.
Solution 9: Rocket Speed Boost
Given

$u = 43{,}200\;\text{km/h}$,   $v = 86{,}400\;\text{km/h}$,   $t = 2.5\;\text{h}$

Unit Conversion
$$t = 2.5 \times 3600 = 9{,}000\;\text{s}$$ $$u = 43{,}200 \times \frac{5}{18} = 12{,}000\;\text{m/s}$$ $$v = 86{,}400 \times \frac{5}{18} = 24{,}000\;\text{m/s}$$
Acceleration
$$a = \frac{v - u}{t} = \frac{24{,}000 - 12{,}000}{9{,}000} = \frac{12{,}000}{9{,}000} = 1.33\;\text{m/s}^2$$
Distance
$$s = \frac{u + v}{2} \times t = \frac{12{,}000 + 24{,}000}{2} \times 9{,}000 = 18{,}000 \times 9{,}000 = 162{,}000{,}000\;\text{m} = 162{,}000\;\text{km}$$
✅ Final Answer $\boxed{a = 1.33\;\text{m/s}^2}$  |  $\boxed{s = 162{,}000{,}000\;\text{m} = 162{,}000\;\text{km}}$
💡 Tip Large speed does not always mean large acceleration. Acceleration depends on change in velocity per unit time.
Solution 10: Fast-Moving Body
Given

$u = 50\;\text{m/s}$,   $a = 20\;\text{m/s}^2$,   $t = 10\;\text{s}$

Final Velocity (1st Equation)
$$v = u + at = 50 + 20 \times 10 = 250\;\text{m/s}$$
Distance (2nd Equation)
$$s = ut + \tfrac{1}{2}\,a\,t^2 = 50 \times 10 + \tfrac{1}{2} \times 20 \times (10)^2$$ $$s = 500 + 1{,}000 = 1{,}500\;\text{m}$$
Average Speed
$$\text{Average Speed} = \frac{\text{Total Distance}}{\text{Total Time}} = \frac{1{,}500}{10} = 150\;\text{m/s}$$
⚡ Shortcut For uniformly accelerated motion: $\text{Average Speed} = \dfrac{u + v}{2} = \dfrac{50 + 250}{2} = 150\;\text{m/s}$
✅ Final Answer $\boxed{v = 250\;\text{m/s}}$  |  $\boxed{s = 1{,}500\;\text{m}}$  |  $\boxed{\text{Average speed} = 150\;\text{m/s}}$
Solution 11: Scooter Acceleration and Cruise
Given — Phase 1 (Acceleration)

$u = 0$,   $a = 2\;\text{m/s}^2$,   $t = 8\;\text{s}$

Speed After 8 s
$$v = u + at = 0 + 2 \times 8 = 16\;\text{m/s}$$
Distance During Acceleration
$$s_1 = ut + \tfrac{1}{2}\,a\,t^2 = 0 + \tfrac{1}{2} \times 2 \times (8)^2 = 64\;\text{m}$$
Phase 2 (Uniform Motion)

The scooter moves uniformly at $16\;\text{m/s}$ for $12\;\text{s}$.

$$s_2 = v \times t = 16 \times 12 = 192\;\text{m}$$
Average Speed
$$\text{Total distance} = 64 + 192 = 256\;\text{m}$$ $$\text{Total time} = 8 + 12 = 20\;\text{s}$$ $$\text{Average speed} = \frac{256}{20} = 12.8\;\text{m/s}$$
✅ Final Answer Speed after 8 s $= 16\;\text{m/s}$  |  $s_1 = 64\;\text{m}$  |  $s_2 = 192\;\text{m}$  |  Average speed $= 12.8\;\text{m/s}$
💡 Tip This is a two-phase problem. Solve one phase at a time.
Solution 12: Elevator Motion
Phase 1 — Speeding Up

$u = 0$,   $v = 6\;\text{m/s}$,   $t = 3\;\text{s}$

$$\text{Average speed} = \frac{u + v}{2} = \frac{0 + 6}{2} = 3\;\text{m/s}$$ $$s_1 = 3 \times 3 = 9\;\text{m}$$
Phase 2 — Slowing Down

$u = 6\;\text{m/s}$,   $v = 0$,   $t = 2\;\text{s}$

$$\text{Average speed} = \frac{6 + 0}{2} = 3\;\text{m/s}$$ $$s_2 = 3 \times 2 = 6\;\text{m}$$
Total
$$\text{Total distance} = 9 + 6 = 15\;\text{m}$$ $$\text{Total time} = 3 + 2 = 5\;\text{s}$$ $$\text{Average speed} = \frac{15}{5} = 3\;\text{m/s}$$
✅ Final Answer Distance speeding up $= 9\;\text{m}$  |  Distance slowing down $= 6\;\text{m}$  |  Total $= 15\;\text{m}$  |  Average speed $= 3\;\text{m/s}$
Solution 13: Free Fall Numeral
Given

$u = 0$,   $g = 10\;\text{m/s}^2$,   $t = 3\;\text{s}$

Velocity After 3 s
$$v = u + g\,t = 0 + 10 \times 3 = 30\;\text{m/s (downward)}$$
Distance Fallen
$$s = ut + \tfrac{1}{2}\,g\,t^2 = 0 + \tfrac{1}{2} \times 10 \times (3)^2 = 5 \times 9 = 45\;\text{m}$$
✅ Final Answer $\boxed{v = 30\;\text{m/s (downward)}}$  |  $\boxed{s = 45\;\text{m}}$
💡 Tip For free fall, acceleration is due to gravity.
Solution 14: Bike Without Time Data
Given

$u = 0$,   $a = 4\;\text{m/s}^2$,   $s = 200\;\text{m}$

Formula Used (3rd Equation — No Time Given)
$$v^2 - u^2 = 2\,a\,s$$ $$v^2 - 0 = 2 \times 4 \times 200 = 1{,}600$$ $$v = 40\;\text{m/s}$$
Finding Time (1st Equation)
$$v = u + at$$ $$40 = 0 + 4\,t \implies t = 10\;\text{s}$$
Average Speed
$$\text{Average Speed} = \frac{u + v}{2} = \frac{0 + 40}{2} = 20\;\text{m/s}$$
✅ Final Answer $\boxed{v = 40\;\text{m/s}}$  |  $\boxed{t = 10\;\text{s}}$  |  $\boxed{\text{Average speed} = 20\;\text{m/s}}$
💡 Tip When acceleration is uniform, Average Speed $= \dfrac{u + v}{2}$.

4. No-Time Alternative Method Section

In these modified scenarios, time is not directly given. The aim is to make students identify whether the situation has equal distance intervals or equal time intervals, then choose the correct average speed formula.

🎯 Big Decision Rule Equal distance?   Use $\dfrac{2\,v_1\,v_2}{v_1 + v_2}$.   Equal time?   Use $\dfrac{v_1 + v_2}{2}$.   Return trip?   Average velocity $= 0$ because displacement $= 0$.

Case 1: Equal Distance Intervals — Straight-Line Motion with Non-Zero Displacement

QNT1
Half Journey Slow, Half Journey Fast

An object covers the first half of a straight-line distance with speed $v$ and the second half with speed $2v$.

  1. Find the average speed.
Solution NT1

For equal distances, do not take the simple average of speeds.

Formula Used
$$\text{Average Speed} = \frac{2\,v_1\,v_2}{v_1 + v_2}$$
Substitution

Here, $v_1 = v$ and $v_2 = 2v$.

$$\text{Average Speed} = \frac{2 \times v \times 2v}{v + 2v} = \frac{4v^2}{3v} = \frac{4v}{3}$$
✅ Final Answer $\boxed{\text{Average speed} = \dfrac{4v}{3}}$
⚠️ Common Trap Do not write $\dfrac{v + 2v}{2} = \dfrac{3v}{2}$. That is only for equal time, not equal distance.

Case 2: Equal Distance Return Trip — Displacement Becomes Zero

QNT2
Boat Goes and Comes Back

A boat travels from a pier to an island at $60\;\text{km/h}$ and returns to the same pier at $120\;\text{km/h}$. The distance in both directions is the same.

  1. Find the average speed.
  2. Find the average velocity.
Solution NT2
Average Speed (Equal Distances)
$$\text{Average Speed} = \frac{2\,v_1\,v_2}{v_1 + v_2} = \frac{2 \times 60 \times 120}{60 + 120} = \frac{14{,}400}{180} = 80\;\text{km/h}$$
Average Velocity

Since the boat returns to the starting point, displacement $= 0$.

$$\text{Average Velocity} = \frac{\text{Total Displacement}}{\text{Total Time}} = 0$$
✅ Final Answer Average speed $= 80\;\text{km/h}$  |  Average velocity $= 0$
💡 Tip Same starting and ending point means zero displacement, not zero distance.

Case 3: Equal Time Intervals

QNT3
Car Moves at Two Speeds for Equal Times

A car moves at $60\;\text{m/s}$ for one time interval and then at $50\;\text{m/s}$ for the same time interval in the same direction.

  1. Find the average speed.
Solution NT3

For equal time intervals, use the simple average of speeds.

$$\text{Average Speed} = \frac{v_1 + v_2}{2} = \frac{60 + 50}{2} = 55\;\text{m/s}$$
✅ Final Answer $\boxed{\text{Average speed} = 55\;\text{m/s}}$
💡 Tip Equal time means arithmetic mean of speeds.

Case 4: Equal Time but Opposite Directions

QNT4
Runner Goes East and Then West

A runner moves east with a speed of $8\;\text{m/s}$ for some time. Then he moves west with a speed of $6\;\text{m/s}$ for the same time.

  1. Find the average speed.
  2. Find the average velocity.
Solution NT4

Let the time in each part be $t$.

Average Speed

Distance east $= 8t$.   Distance west $= 6t$.

$$\text{Total distance} = 8t + 6t = 14t$$ $$\text{Total time} = 2t$$ $$\text{Average Speed} = \frac{\text{Total Distance}}{\text{Total Time}} = \frac{14t}{2t} = 7\;\text{m/s}$$
Average Velocity

Taking east as positive:

$$\text{Displacement} = 8t - 6t = 2t \;\text{(east)}$$ $$\text{Average Velocity} = \frac{\text{Displacement}}{\text{Total Time}} = \frac{2t}{2t} = 1\;\text{m/s (east)}$$
✅ Final Answer Average speed $= 7\;\text{m/s}$  |  Average velocity $= 1\;\text{m/s (east)}$
⚠️ Common Trap Average speed uses total distance. Average velocity uses displacement.

Case 5: Equal Distance with Real Numbers

QNT5
City Drive

A car covers the first half of a straight road at $40\;\text{km/h}$ and the second half at $60\;\text{km/h}$.

  1. Find the average speed.
Solution NT5

The two distance intervals are equal, so use the equal-distance formula.

$$\text{Average Speed} = \frac{2\,v_1\,v_2}{v_1 + v_2} = \frac{2 \times 40 \times 60}{40 + 60} = \frac{4{,}800}{100} = 48\;\text{km/h}$$
✅ Final Answer $\boxed{\text{Average speed} = 48\;\text{km/h}}$
⚠️ Common Trap Many students write $50\;\text{km/h}$, but that is wrong because distance intervals are equal, not time intervals.

Case 6: Equal Time with Real Numbers

QNT6
Two Equal Time Speed Runs

A scooter moves at $30\;\text{km/h}$ for one time interval and $50\;\text{km/h}$ for the same time interval.

  1. Find the average speed.
Solution NT6

The two time intervals are equal, so use the simple average of speeds.

$$\text{Average Speed} = \frac{v_1 + v_2}{2} = \frac{30 + 50}{2} = 40\;\text{km/h}$$
✅ Final Answer $\boxed{\text{Average speed} = 40\;\text{km/h}}$

Equal distance $\text{Avg Speed} = \dfrac{2\,v_1\,v_2}{v_1 + v_2}$ Distance equal → harmonic-type average
Equal time $\text{Avg Speed} = \dfrac{v_1 + v_2}{2}$ Time equal → simple average
Return to starting point $\text{Average Velocity} = 0$ Displacement becomes zero
Stopping motion $v = 0$ and acceleration is negative Retardation means slowing down
Time missing in equations of motion Use $v^2 - u^2 = 2\,a\,s$ No time? Use third equation

Before solving any Motion numerical, pause for 5 seconds and identify: Is it average speed? Is it acceleration? Is time missing? Is the object stopping? This choice of formula is half the solution.
